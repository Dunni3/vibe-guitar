How filters shape frequencies

A digital filter is a few multiplications and additions per sample. This lesson shows how that arithmetic decides which frequencies get louder or quieter. It starts from the rule y[n] = x[n] + a·y[n−1] and builds up to poles, zeros and the Fourier transform, with something to drag at every step.

01The simplest feedback filter

A digital audio signal is a list of numbers. Each number is called a sample, and it records the height of the sound wave at one instant. This page assumes 48,000 samples per second (the sample rate), so one sample lasts about 0.02 milliseconds and 48 samples last one millisecond.

We write x[n] for sample number n of the input and y[n] for sample number n of the output. So x[n−1] is the input one sample earlier. A filter is a rule for computing each output sample from input samples and earlier output samples.

Here is the simplest rule that feeds the output back into itself. Each new output is the new input plus a fraction a of the previous output:

y[n] = x[n] + a·y[n−1]

The rule mentions a past output, but that past output was itself computed by the same rule. Substitute the rule into itself, again and again:

y[n] = x[n] + a·y[n−1]
     = x[n] + a·( x[n−1] + a·y[n−2] )
     = x[n] + a·x[n−1] + a2·x[n−2] + a3·x[n−3] + …

The past outputs have disappeared. The output is a weighted sum of the current input and every earlier input. The input from k samples ago gets the weight ak. Call that weight h[k]. The symbol Σ means “add up one term for each value of k”:

y[n] = Σk=0…∞ h[k] · x[n−k]    with   h[k] = ak

A weighted sum of this shape, where weight number k multiplies the input from k samples ago, is called a convolution.

The feedback rule and the infinite sum are the same filter written two ways. The single number y[n−1] already contains the weighted sum of every older input, so feedback works as compressed memory. One multiply and one add per sample compute a sum with infinitely many terms.

The list of weights h is called the impulse response. An impulse is the input 1, 0, 0, 0, … (a single click). Feed it in and the output is exactly h[0], h[1], h[2], …, because the sum above then has only one nonzero term. Any filter built from adding, scaling and delaying is fully described by its impulse response.

Bench 1 · impulse response h[k] = ak
Each stem is one weight h[k]. The first stem is k = 0.
0.80
  • 0 < a < 1: a smooth, decaying tail. Each input sample is smeared into the following ones. Smearing evens out rapid changes and leaves slow changes alone. A filter that keeps slow changes (low frequencies, bass) and reduces rapid ones (high frequencies, treble) is called a low-pass. It makes the tone darker.
  • a < 0: the tail flips sign every sample. That strengthens signals that also flip rapidly, and weakens slow ones. This is the opposite behavior, a high-pass, and it makes the tone brighter.
  • |a| ≥ 1: the tail never shrinks, or it grows. A filter whose impulse response dies away is called stable. One whose response keeps growing is unstable: a single click produces output that gets louder forever, which through an amplifier is a runaway squeal.

02The general recipe

The rule in section 1 is the smallest member of a family. Allow two past inputs and two past outputs, each with its own multiplier:

y[n] = b0·x[n] + b1·x[n−1] + b2·x[n−2] + a1·y[n−1] + a2·y[n−2]

The five multipliers are called coefficients.

  • The b’s are feedforward coefficients: they multiply recent inputs. With only b’s, an impulse comes out as b0, b1, b2, then silence. A filter like that is called FIR, for finite impulse response.
  • The a’s are feedback coefficients: they multiply recent outputs. Any feedback gives an impulse response that goes on forever (shrinking, if the filter is stable). A filter like that is called IIR, for infinite impulse response.

This five-coefficient filter is called a biquad. It is the standard building block of audio processing. The bands of an equalizer (a device that boosts or cuts chosen ranges of frequency), tone knobs and wah pedals are usually biquads, often several in a row. The filter from section 1 is the biquad with b0 = 1, a1 = a, and the other three set to zero.

Sign convention: textbooks, SciPy and the Web Audio API write the feedback terms with minus signs, y[n] = … − a1y[n−1] − a2y[n−2]. That is the same filter with a1 and a2 negated. This page uses plus signs throughout.

The trouble with coefficients is that they are hard to read. If a1 = 1.97 and a2 = −0.98, what does the filter sound like? Nothing about those numbers says. To answer, we need to ask what a filter does to each frequency. Section 6 comes back to these two numbers and reads them.

03One frequency in, the same frequency out

First, three definitions. A sine wave is the smoothest possible repeating wave, and it sounds like a pure whistle. It is described by three numbers:

  • Frequency: how many full up-and-down cycles it completes per second, measured in hertz (Hz). Low frequencies sound like bass, high frequencies like treble. The low A string of a guitar is 110 Hz.
  • Amplitude: how tall the wave is, from the middle to a peak. Taller is louder.
  • Phase: where in its cycle the wave is at a given moment. Phase is measured in degrees, with 360° meaning one whole cycle. Two waves of the same frequency that are 90° apart reach their peaks a quarter of a cycle apart.

Here is the central fact of this page. Feed a sine wave into one of these filters, wait a moment for the output to settle, and the output is a sine wave of the same frequency. Only two things can differ:

  • its amplitude. The gain is the output amplitude divided by the input amplitude. A gain of 2 means twice as tall, 0.5 means half as tall.
  • its phase. The phase shift is how far the output wave is slid along in time compared with the input, in degrees of a cycle. A phase shift of −90° means the output peaks a quarter cycle after the input.

The reason is that the filter performs only three operations: scale, delay and add. A scaled sine is a sine of the same frequency. A delayed sine is a sine of the same frequency. And adding two sines of the same frequency gives another sine of that frequency. If their peaks line up, the sum is taller. If one peaks where the other dips, they cancel. Anything in between gives a sine of intermediate height and timing. (Section 4 has a moving picture of this last claim.)

This matters because real sounds are sums of sines. A guitar note at 110 Hz is a sine at 110 Hz, called the fundamental, plus quieter sines at 220, 330, 440 Hz and so on, called harmonics. And since the filter only scales, delays and adds, filtering a sum gives the same result as filtering each part separately and adding the results. So the filter handles every sine in the note independently.

That means a filter is completely described by a table: for each frequency, one gain and one phase shift. This table is the filter’s frequency response. It is the exact mathematical link between a filter’s coefficients and what it does to sound.

The bottom curve was drawn from a formula, with no simulation. Deriving that formula takes one idea, and the idea needs complex numbers. The next section builds them from a picture.

04Sine waves as spinning arrows

Draw a circle of radius 1 and an arrow from its center to its edge. Let the arrow turn counterclockwise at a steady rate. Watch only the height of the arrow’s tip above the center: it rises, falls, goes negative and comes back. That height, traced over time, is a sine wave. One full turn of the arrow is one cycle of the wave.

In a digital signal we only see the arrow once per sample. Between one sample and the next it turns by some fixed angle. Call that angle ω (the Greek letter omega). A larger ω means fewer samples per turn, so a higher frequency. Precisely: a full turn is 360°, so one cycle takes 360°/ω samples, and there are 48,000 samples per second, so

f = (ω / 360°) × 48,000 Hz ω in degrees per sample

For example, ω = 20° means 18 samples per cycle, which is 48,000 / 18 ≈ 2,667 Hz.

The readout also gives ω in radians, the angle unit textbooks use. A full turn is 2π ≈ 6.283 radians instead of 360°. It is the same angle in different units, like inches and centimeters.

Adding two sines of the same frequency

This picture also settles the claim from section 3. Two sines of the same frequency are two arrows turning at the same rate. Call them A and B. To add them, slide B so that it starts at the tip of A. The sum arrow runs from the center to the tip of B. Its height is the height of A plus the height of B, at every instant.

Because A and B turn at the same rate, the angle between them never changes. The triangle they form with the sum arrow keeps its shape and turns as one rigid piece. So the sum arrow has a fixed length and turns at that same rate, which means its height traces a sine of the same frequency. Its length is the new amplitude, and the angle between it and A is the phase shift.

The three buttons jump to the settings worth seeing, each with B size at 1 (B lead is how many degrees B is ahead of A). With B lead at 0° the arrows line up and the sum is twice as tall. With 180° they point in opposite directions and the sum vanishes: the two sines cancel. With 90° the sum is about 1.41 times as tall and sits halfway between them in timing. A filter’s output is built this way, from scaled and delayed copies of one sine, and the copies combine into a single sine with a new amplitude and phase.

The fastest possible frequency

Set ω to 180°. The arrow jumps between two opposite points, so the signal alternates +, −, +, −. No sampled signal can change faster than that. This top frequency is half the sample rate, 24,000 Hz, and is called the Nyquist frequency.

Push ω past 180° and the wave appears to slow down again. A step of 200° forward lands on the same point as a step of 160° backward, and from the samples alone the two cannot be told apart. A frequency above Nyquist showing up disguised as a lower one is called aliasing. The consequence for this page: the angles from 0° to 180°, the top half of the circle, cover every frequency a 48,000-sample-per-second signal can hold, from 0 Hz to 24,000 Hz.

Complex numbers: arithmetic for arrows

To calculate with arrows we need a way to write them down and combine them. That is what complex numbers are. A complex number is a point on a flat plane, or equally the arrow from the center to that point. There are two ways to describe one:

  • by position: how far right and how far up. The point 3 right and 2 up is written 3 + 2i. The symbol i is the name of the point one unit straight up.
  • by length and angle: how long the arrow is, and how far it is turned counterclockwise from pointing right.

Ordinary numbers live on the horizontal line through the center. Positive numbers point right (angle 0°). Negative numbers point left (angle 180°). Everything off that line is new.

There are two operations, and each has a simple geometric meaning:

  1. Adding two complex numbers places the arrows tip to tail. The rightward parts add and the upward parts add. Subtracting works the same way in reverse, which gives a useful fact: p − q is the arrow that reaches from point q to point p, so the length of p − q is the distance between the two points.
  2. Multiplying two complex numbers multiplies their lengths and adds their angles. Dividing does the reverse: divide the lengths, subtract the angles.

The multiplication rule agrees with ordinary arithmetic. A negative number has angle 180°, so negative times negative has angle 360°, which points right: positive. It also explains the famous property of i. Since i has length 1 and angle 90°, i × i has length 1 and angle 180°. That is the number −1. Nothing mysterious is going on: “imaginary” is a historical name for the vertical direction.

The length of a complex number c is written |c|.

The number z

The meaning of ω has not changed: it is still the angle the arrow turns between one sample and the next. Now we package that step as a complex number. Let z be the number with length 1 and angle ω. It sits on the circle of radius 1 around the center, which is called the unit circle.

Two different things are now on the circle, and it is important to keep them apart:

  • z is fixed. It does not move from sample to sample. It is the step: multiplying any arrow by z keeps its length (×1) and turns it forward by ω. Choosing a frequency means choosing ω, which means choosing where z sits. That is why each point on the top half of the circle stands for one frequency.
  • The spinning arrow moves. It is the signal. It starts pointing right, at the number 1, and is multiplied by z once per sample.

Follow the arrow sample by sample. Write x[n] for the arrow’s position at sample n:

SampleArrow positionIts angle
n = 010

The angles add because multiplying adds angles, and the length stays 1 because 1 × 1 = 1. So zn, meaning z multiplied by itself n times, has length 1 and angle n·ω. The whole spinning arrow from bench 3 is one formula:

x[n] = zn position at sample n = n steps of z

Notice that z itself happens to be the arrow’s position at sample 1. That is the only moment the two coincide. With ω = 20°, z stays at 20° forever, while the arrow visits 0°, 20°, 40°, 60°, …

Here each x[n] is a whole arrow, a point on the circle, and not a single ordinary number. An actual audio sample is only the arrow’s height, and a height alone does not say where on the circle the arrow is. The subsection after next explains why it is still correct to calculate with whole arrows.

One more piece of notation: z−1 means 1 ÷ z. It has length 1 and angle −ω, so multiplying by it turns an arrow backward by ω. It undoes one step.

Textbooks write z as eiω. Read that as a label meaning “the point on the unit circle at angle ω” and nothing more is needed here.

And here is the payoff. The arrow’s position one sample earlier is

x[n−1] = zn−1 = zn · z−1 = x[n] · z−1

For a spinning arrow, delaying by one sample is the same as multiplying by z−1. A filter is made of delays, scalings and additions. For this kind of input, all three become ordinary arithmetic, and a filter equation becomes algebra.

Arrows versus the real signal

A real audio signal is a single ordinary number per sample, not an arrow. The real signal is the arrow’s height. Working with the whole arrow is still valid, for this reason: the filter’s coefficients are ordinary numbers. Scaling an arrow by an ordinary number scales its height by that number. Adding two arrows adds their heights. Delaying an arrow delays its height. So if we filter the arrow and then take the height of the result, we get exactly what we would get by filtering the heights directly. We calculate with arrows because the algebra is easy, then read off the height at the end.

05The feedback filter, solved for every frequency

Take the filter from section 1, y[n] = x[n] + a·y[n−1], and feed it the spinning arrow x[n] = zn.

Section 3 said the settled output has the same frequency, with a different amplitude and phase. In arrow terms: the output is the same spinning arrow, stretched by some factor and turned by some fixed angle. Stretching and turning is exactly what multiplying by a complex number does. So the output must have the form

y[n] = H · zn

where H is one fixed complex number that does not change from sample to sample. Its length |H| is the gain. Its angle is the phase shift. Finding H is the whole problem. Substitute both signals into the filter rule:

H·zn = zn + a·H·zn−1 substitute
H = 1 + a·H·z−1 divide everything by zⁿ
H − a·H·z−1 = 1 move the H terms left
H·(1 − a·z−1) = 1 factor out H
H = 1 / (1 − a·z−1) divide
H = z / (z − a) multiply top and bottom by z

The sample number n cancelled out, which confirms that one fixed H works for all time. The result depends on z, and z depends on the frequency, so this single formula is the frequency response: pick a frequency, find its z on the circle, compute H.

About “settled”: when a sine is first switched on, the output is H·zn plus a leftover that shrinks like an, the same decaying tail as in bench 1. After that leftover has faded, only H·zn remains.

The gain is a distance

The gain is the length of H. Dividing complex numbers divides their lengths, so

gain = |H| = |z| / |z − a| = 1 / |z − a|

The top is 1 because z is on the unit circle. The bottom, by the subtraction fact from section 4, is the distance from the point z to the point a. The point z is your frequency’s spot on the circle. The point a is the filter’s coefficient, sitting on the horizontal line.

gain at a frequency = 1 ÷ (distance from that frequency’s point to a)

Two words come from this formula. A pole of a filter is a value of z that makes the bottom of H zero, so that H becomes infinite. Here the bottom is z − a, so there is one pole, at z = a. A zero is a value of z that makes the top zero, so that H = 0. Here the top is z, so there is one zero, at the center. Frequencies live on the circle and never land exactly on the pole, but the closer a frequency’s point is to the pole, the larger its gain. The name comes from picturing the gain as a tent held up by a pole at that spot.

With a = 0.9 the pole sits just inside the circle next to the 0 Hz point. Low frequencies are about 0.1 away from it, so their gain is about 10. The 24 kHz point is on the far side, 1.9 away, so its gain is about 0.53. That is the whole low-pass curve from bench 2, obtained with a ruler. Slide the pole to the left side and the high frequencies become the near ones: a high-pass.

The zero at the center does nothing to the gain, because every point of the circle is the same distance, 1, from the center.

Stability also has a place in this picture. In bench 1 the filter was stable when |a| < 1. In the picture that reads: the pole is inside the unit circle. A pole outside the circle is the growing tail. In that case the output never settles, and the gain formula stops describing anything real.

06Poles and zeros: a map of any filter

The same method solves the biquad from section 2. Feed in x[n] = zn, assume the output is H·zn, and remember that each sample of delay is one factor of z−1:

H·zn = (b0 + b1z−1 + b2z−2)·zn + (a1z−1 + a2z−2)·H·zn
H·(1 − a1z−1 − a2z−2) = b0 + b1z−1 + b2z−2 divide by zⁿ, collect H
H = (b0 + b1z−1 + b2z−2) / (1 − a1z−1 − a2z−2)
H = (b0z2 + b1z + b2) / (z2 − a1z − a2) multiply top and bottom by z²

The feedforward coefficients ended up on top and the feedback coefficients on the bottom. Both are quadratics in z. Any quadratic can be rewritten as a product of two factors, one for each of its roots (the values of z that make it equal zero):

H = b0 · (z − q1)(z − q2) / ( (z − p1)(z − p2) )

The roots of the top, q1 and q2, are the filter’s two zeros. The roots of the bottom, p1 and p2, are its two poles. These roots are complex numbers, so each one is a point on the plane.

Take lengths, exactly as in section 5. Each factor like |z − p1| is the distance from the frequency point to that pole or zero:

gain = b0 × (dist. to q₁) × (dist. to q₂)
       ÷ (dist. to p₁) ÷ (dist. to p₂)

Five hard-to-read coefficients have become four points on a map plus a volume setting b0. A frequency close to a zero gets a small gain. A frequency close to a pole gets a large gain. The drawing of a filter’s poles (marked ×) and zeros (marked ○) is called a pole–zero plot.

One rule limits where the points can go. When a root is not on the horizontal line, the quadratic’s other root is its mirror image across that line. This happens because the coefficients are ordinary numbers. So poles and zeros off the line always come as mirrored pairs, and the playground below moves each pair together.

  • The playground picks b0 automatically so the loudest frequency sits at 0 dB. Only the shape of the curve changes as you drag.

What to notice while you drag

  • Pole angle chooses which frequency is boosted, since the nearest point of the circle is at that same angle.
  • Pole distance from the circle sets how narrow and tall the peak is. A strong, narrow peak is called a resonance. It also sets how long the filter rings, meaning how long it keeps oscillating after the input stops. The impulse response shrinks by a factor of r every sample, so the closer r is to 1, the longer the ring. The readout’s “rings” figure is the time for the tail to fall to one thousandth of its size.
  • Load “Wah” and press “Rock the pedal”. The pole pair sweeps back and forth in angle, staying close to the circle. That moving resonance is the wah sound.
  • A zero exactly on the circle has distance 0 to one frequency point, so that frequency’s gain is 0. It is removed completely. A narrow cut like this is called a notch.
  • A pole outside the circle makes the filter unstable, as in section 5. Drag one out and watch the impulse response grow.
  • A pole and a zero at the same spot cancel, because their distances are equal and one multiplies while the other divides. Slightly apart, they nearly cancel everywhere except at nearby frequencies. The EQ boost preset is exactly this: the pole a little closer to the circle than the zero, producing a small bump.
  • Press Zoom. A guitar’s useful range, roughly 80 Hz to 5,000 Hz, occupies only the first 37° of the circle, because 5,000 / 48,000 × 360° ≈ 37°. Nearly all tone shaping happens in that sliver, which is why audio poles and zeros crowd together near the 0 Hz point.

From the picture back to coefficients

Suppose the pole pair is at distance r from the center, at angles +θ and −θ. The two poles have the same rightward part, r cos θ, and opposite upward parts. Multiplying out the bottom of H gives

(z − p1)(z − p2) = z2 − (2r cos θ)·z + r2

The middle term is p1 + p2, where the upward parts cancel. The last term is p1 × p2: lengths multiply to r2 and the angles +θ and −θ add to zero. Compare with the bottom of H, which was z2 − a1z − a2. The same steps work for a zero pair at distance ρ and angle φ. Matching terms:

a1 = 2r cos θ    a2 = −r2
b1 = −2ρ cos φ · b0    b2 = ρ2 · b0

These formulas convert a design made on the map into the five numbers a program needs. They also run backward. Section 2 asked what a1 = 1.97 and a2 = −0.98 sound like. From a2 = −r2, r ≈ 0.99. From a1 = 2r cos θ, θ ≈ 5.7°. That is a pole pair very close to the circle at 5.7° / 360° × 48,000 ≈ 760 Hz: a sharp, ringing resonance near 760 Hz.

07Where Fourier comes in

There is a second route to the frequency response, and it starts from the impulse response. Section 1 showed that any of these filters can be written as a weighted sum of past inputs, y[n] = Σ h[k]·x[n−k]. Feed in the spinning arrow x[n] = zn:

y[n] = Σk h[k] · zn−k = zn · Σk h[k] · z−k

The output is zn times something that does not depend on n. That something must be H:

H = Σk h[k] · z−k    z = the point at angle ω

This formula is the Fourier transform of the list h. In general, a Fourier transform takes any list of numbers and, for each frequency, returns one complex number. Its length says how much of that frequency the list contains. Its angle says how that component is positioned in time.

Here is why the formula measures “how much of a frequency”. Each term h[k]·z−k is an arrow of length h[k], turned backward by k steps of ω. Suppose h itself rises and falls at the frequency belonging to ω. Then the backward turning cancels that rhythm, the arrows end up pointing in a common direction, and they add to a long arrow. If h has no rhythm at that frequency, the arrows point in scattered directions and mostly cancel. The transform runs this test for every frequency.

So the frequency response of a filter is the Fourier transform of its impulse response. The two descriptions of a filter, one in time and one in frequency, carry the same information.

Check it on the filter from section 1, where h[k] = ak. Each term is (a·z−1)k. A sum of the form S = 1 + c + c2 + c3 + … satisfies S = 1 + c·S, which gives S = 1/(1 − c), provided the terms shrink (|c| < 1). With c = a·z−1:

Σk akz−k = 1 / (1 − a·z−1)

That is the same H found in section 5. The condition for the sum to work, |a| < 1, is the stability condition once more.

Three consequences

  • Chaining filters multiplies their responses. Send a spinning arrow through one filter and it is multiplied by H1. Send the result through a second and it is multiplied by H2. The pair acts as the single response H1·H2: gains multiply and phase shifts add. In decibels the gains add, because decibels are logarithms. So the curve of a chain of effects is the sum of the individual dB curves.
  • Signals have Fourier transforms too. The transform of a signal is called its spectrum: how much of each frequency it contains. Filtering multiplies the signal’s spectrum by H, frequency by frequency. The convolution of section 1, a complicated sliding sum in time, is plain multiplication in frequency.
  • The z-plane. The formula for H makes sense for any complex number z, not only those on the unit circle. Treated that way, as a function over the whole plane, it is called the z-transform, and the plane is called the z-plane. Poles and zeros are features of that function. The frequency response is the part of it that lies along the unit circle.

08Long delays make combs

So far the feedback reached back one or two samples. Now reach back D samples, with a feedback multiplier g:

y[n] = x[n] + g·y[n−D]

A delay of D samples is a factor of z−D, so the same algebra as section 5 gives

H = 1 / (1 − g·z−D) = zD / (zD − g)

The poles are where the bottom is zero: zD = g. Raising z to the power D raises its length to that power and multiplies its angle by D. For the result to equal the positive number g, the length must be the D-th root of g, and D times the angle must be a whole number of full turns. That allows the angles 0°, 360°/D, 2 × 360°/D, and so on. So there are D poles, evenly spaced around a circle just inside the unit circle.

Each pole lifts the gain at the frequency nearest to it, so the response has evenly spaced peaks, one every 48,000/D Hz. The shape looks like the teeth of a comb, and the filter is called a comb filter.

Raising g moves the poles toward the unit circle, which makes the peaks sharper and the ringing longer. Two familiar effects are comb filters:

  • A flanger uses a short delay, roughly 1 to 10 milliseconds (48 to 480 samples), and slowly varies it. The peaks slide up and down the spectrum, which gives a sweeping, jet-like sound.
  • An echo uses a delay of hundreds of milliseconds. The peaks are then packed so densely that the ear no longer hears a change in tone. It hears the repeats themselves, each one g times as loud as the last.

09In code

A biquad costs five multiplications and four additions per sample, which is very little work. Even a small computer such as a Raspberry Pi can run hundreds of them on live audio.

Here is the biquad as a plain loop. The four variables hold the two previous inputs and two previous outputs. They are the filter’s memory, and they must persist between calls.

x1 = x2 = y1 = y2 = 0.0     # previous inputs and outputs

def tick(x):                # one input sample in, one output sample out
    global x1, x2, y1, y2
    y = b0*x + b1*x1 + b2*x2 + a1*y1 + a2*y2
    x2, x1 = x1, x          # shift the input history
    y2, y1 = y1, y          # shift the output history
    return y

Live audio software receives samples in groups called blocks, typically 64 to 512 samples at a time. In Python a per-sample loop is slow, so the usual approach is to hand each whole block to SciPy’s lfilter, which runs the same loop in compiled code. The filter’s memory has to be carried from one block to the next. If it is reset, the output jumps at every block boundary and you hear a click.

import numpy as np
from scipy.signal import lfilter

b = [b0, b1, b2]
a_scipy = [1.0, -a1, -a2]   # SciPy uses the minus-sign convention
state = np.zeros(2)         # the filter's memory between blocks

def process(block):         # block: array of samples from the audio interface
    global state
    out, state = lfilter(b, a_scipy, block, zi=state)
    return out
